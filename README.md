# DispatchHalo

DispatchHalo is a working business concept for a managed, 24/7 emergency-intake and dispatch service serving independent water, fire, and mold restoration companies.

The service is designed to answer overflow and after-hours calls, qualify the loss, check service-area rules, notify the correct on-call technician, escalate unanswered dispatches, and report measurable outcomes.

## Repository contents

- `site/index.html` — responsive customer-facing landing page with an interactive call-leak calculator
- `site/og.png` — branded social-preview image
- `docs/founder-blueprint.md` — positioning, offer, financial model, automation architecture, sales scripts, onboarding, safeguards, and 90-day launch plan

## Live site

[https://rmazin.github.io/dispatchhalo/](https://rmazin.github.io/dispatchhalo/)

GitHub Actions publishes the contents of `site/` to GitHub Pages whenever `main` changes.

## Preview the site locally

From the repository root:

```bash
python3 -m http.server 4173 --directory site
```

Then open `http://127.0.0.1:4173`.
